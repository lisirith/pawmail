# GitHub 发布页文字（v0.1.0）

第三步在 GitHub 上建 Release 时用：Tag 填 `v0.1.0`，标题填下面的"Title"，正文粘贴"Notes"，
再把 `dist/` 里的 `Pawmail-Setup-0.1.0.exe` 和 `Pawmail-0.1.0-win-x64.zip` 拖进附件，勾选"This is a pre-release"。

---

## Title

Pawmail 0.1.0 beta · 爪爪来信 0.1.0 测试版

## Notes

The first public beta of Pawmail, a tiny desktop pet that writes you a letter every day.

**Download one of these:**

- `Pawmail-Setup-0.1.0.exe`: installer (installs for your account, no admin needed)
- `Pawmail-0.1.0-win-x64.zip`: no install; unzip and run `Pawmail.exe`

Windows 10 / 11, 64-bit. The first time you run it, Windows may show *"Windows protected your PC"*: click **More info → Run anyway**. Pawmail isn't code-signed yet.

There's no automatic update yet. When a new version comes out, install it over this one; your letters carry over.

Found a bug? Please [open an issue](../../issues).

---

爪爪来信的第一个公开测试版：一只每天给你写一封信的桌面小宠物。

**二选一下载：**

- `Pawmail-Setup-0.1.0.exe`：安装程序（只装给你自己，不需要管理员权限）
- `Pawmail-0.1.0-win-x64.zip`：免安装，解压后运行 `Pawmail.exe`

支持 Windows 10 / 11（64 位）。第一次运行时 Windows 可能提示"Windows 已保护你的电脑"，点 **更多信息 → 仍要运行**（暂时还没有代码签名）。

暂时不会自动更新。出新版本时直接装在这个版本上面就行，信都还在。

发现问题？欢迎[提 issue](../../issues)。
